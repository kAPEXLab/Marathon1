# Q2: Implement, Build and Unit Test a C Program

Complete the C programming problem **“Button Debounce with Event Callback”** given at the link below:

[Button Debounce with Event Callback](https://kapexlab.github.io/C-Programming/Question-Bank/08-function-pointers-and-callbacks/Q1-Button-Debounce-Callback.html)

The problem requires you to implement button debounce logic and use a **function pointer as a callback**. The callback must be invoked according to the conditions specified in the problem statement.

After completing the problem, create a build and unit-testing setup for your solution.

## Requirements

Your submission shall:

1. Implement the problem exactly as specified in the given programming question.

2. Implement the solution using a **multi-file approach**, separating the program into appropriate source (`.c`) and header (`.h`) files.

3. Ensure that function declarations are placed in appropriate header files and function implementations are placed in corresponding source files.

4. Create a **Makefile** to compile and build the project.

5. Create **GoogleTest (gtest)** unit tests in a separate `.cpp` file.

6. Convert **all test cases provided in the original programming question** into automated GoogleTest test cases.

7. For each test case, verify the expected return value, callback behaviour, and output as specified in the original question.

8. Ensure that the GoogleTest cases correctly verify whether the callback is invoked or not invoked as required by each test condition.

9. Ensure that all the specified GoogleTest test cases pass successfully.

## Submission Instructions

- Include all required `.c`, `.h`, `.cpp`, and `Makefile` files.
- Place all the required files in a **single ZIP file**.
- Name the ZIP file using the following format:

  `Q2_PRN.zip`

- Replace `PRN` with your actual **PRN number**.

  Example:

  `Q2_123456.zip`

- Upload the ZIP file to **Moodle → Q2**.
